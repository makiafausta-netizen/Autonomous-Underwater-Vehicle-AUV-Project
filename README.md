# Autonomous Underwater Vehicle (AUV) — RoboSub Project Portfolio

**Role:** Robotics Software Engineer / Autonomy Developer  
**Technologies:** C++, Python, ROS2, Linux, Embedded Systems  
**Hardware:** RGB Camera, IMU, Ultrasonic Sensors, Pressure Sensors, Arduino / STM32  
**Focus Areas:** Autonomous Navigation, Sensor Fusion, Real-Time Systems, Robotics Software, Embedded Control

---

# Project Overview

Developed modular autonomy software for an Autonomous Underwater Vehicle (AUV) capable of performing navigation, perception, and mission execution in dynamic underwater environments.

The system integrates real-time sensor processing, control algorithms, and autonomous decision-making to enable reliable vehicle operation during underwater missions. The project emphasizes robust robotics software architecture, low-latency perception pipelines, and embedded control systems similar to real-world robotic platforms.

---

# Key Contributions

## Autonomy Software Architecture

- Designed and implemented ROS2-based autonomy modules in **C++ and Python** for navigation, perception, and mission logic.
- Developed modular software components enabling real-time communication between perception, control, and state estimation subsystems.

## Sensor Fusion & State Estimation

- Implemented multi-sensor fusion pipelines combining **IMU, ultrasonic sensors, pressure sensors, and RGB camera input** to support robust vehicle localization and situational awareness.
- Processed sensor data streams in real time to improve navigation accuracy and environmental perception in underwater environments.

## Autonomous Navigation & Control

- Developed event-driven mission logic enabling autonomous obstacle detection, avoidance, and mission sequencing.
- Implemented closed-loop control algorithms to stabilize vehicle depth, heading, and motion using real-time feedback from onboard sensors.

## Real-Time Systems & Embedded Integration

- Integrated embedded microcontrollers (**Arduino / STM32, Raspberry Pi Pico**) with onboard Linux computing systems for low-latency actuator control and sensor acquisition.
- Established tethered Ethernet communication to enable live telemetry, debugging, and real-time software updates during underwater testing.

## Perception & Vision Processing

- Utilized an RGB camera system to perform real-time visual sensing and environmental awareness for obstacle detection and navigation tasks.

## Testing, Debugging, and System Validation

- Conducted extensive simulation-based validation, mission rehearsal testing, and live underwater trials to evaluate system reliability and autonomy performance.
- Diagnosed and resolved sensor noise, timing synchronization issues, and control instabilities during field testing.

## Mechanical Design & System Integration

- Designed and fabricated structural components using **CAD, 3D printing, and Finite Element Analysis (FEA)** to ensure durability under underwater pressure conditions.
- Implemented sealing strategies and integration methods to maintain full system waterproofing and operational reliability.

## Technical Documentation

- Authored detailed engineering documentation describing system architecture, data flow pipelines, testing procedures, and control logic to support maintainability and team collaboration.
